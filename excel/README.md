# excel/

A planilha do OP% (`OP_Sistema.xlsx`) é pessoal e **não** é versionada (está no `.gitignore`).

O app exporta uma planilha com as mesmas abas (REGISTRO, CHECKIN, ROTINA, METAS, REVISÃO, FOLGAS) e uma aba **BASE** (um dia por linha), pronta para Power BI e Python: em Ajustes → Dados e backup → Planilha (.xlsx).
